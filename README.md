# StarHUD NeoForge

Unofficial port of [StarHUD](https://github.com/Finsider/starhud) by Finside to NeoForge 1.21.1.

All HUD elements from the original are preserved: armor, hand, coordinates, clock, compass, stats, status effects, and more.

## Original

- **Author:** Finside
- **Original project:** https://github.com/Finsider/starhud
- **License:** MIT

This port maintains the same MIT license. See [LICENSE](LICENSE).

## Notes

- The original Fabric build runs on NeoForge via [Synitra Connector](https://modrinth.com/mod/synitra-connector). This port is a native NeoForge version with no Fabric dependency.
